# 蘇滬混合腔韻圖

吳語（蘇州—上海混合腔）的**現代韻圖**。線上瀏覽：<https://siqyin.github.io/wugniu_yundu/>

韻圖按今音韻基分韻，每韻再分開、合、齊、撮四呼，一呼一位、一位一圖；
每格是一個小韻（＝一個合法音節）。全圖共 **28 韻 / 48 呼位 / 27 聲母 / 7 聲調**。

表中的音標**一律是音值**（實際讀音），不列音位。

## 聲母

27 個（含零聲母）。零聲母分清濁：**陰平・陰上・陰去・陰入為清零，
陽平・陽上去・陽入為濁零**。

| 五音 | 聲母 |
|---|---|
| 唇 | 幫 p・滂 pʰ・並 b・明 m・非 f・奉 v |
| 舌 | 端 t・透 tʰ・定 d・儂 n・來 l |
| 牙 | 該 k・開 kʰ・搿 ɡ・牙 ŋ |
| 喉 | 好 h・匣 ɦ |
| 腭 | 見 tɕ・溪 tɕʰ・群 dʑ・曉 ɕ・孃 ȵ |
| 齒 | 精 ts・親 tsʰ・心 s・邪 z |
| 零 | ∅ |

- 聲母名稱由雪螢在 2026 年 10 月 7 日命名，**非強制**，但雪螢建議大家使用。
- 注音符號 `ȵ` 只在顯示層替換；比對字典寫法與解析規則時仍用語法鍵 `gn`。
- 明 m、儂 n、來 l、孃 ȵ 搭配陰聲調時的 `ʔm ʔn ʔl ʔȵ` 是正常讀音，不另立聲母。

- **四呼判定**：介音或主元音為 `u` 者合口，為 `i` 者齊齒，為 `iu`／〔y〕者撮口，
  餘為開口。y〔ɿ〕和 yu〔ʮ〕兩個韻都視作開口。
- **韻目取字都經過核驗**：每個韻目字都在本韻內確實有該讀音（由 `build_data.py` 斷言）。

### 韻目名稱的由來

韻目名稱由雪螢在 2026 年 10 月 7 日命名。該名稱**非強制**，但雪螢建議大家使用。
選字依據蘇滬混合腔的實際讀音，原則上不採用可能造成歧義的多音字。

例外有**月韻**與**質韻**兩個：

- **月**：`gniuq8`、`yuq8` 兩音均為月韻，但另有 `ngeq8`（蘇州音白讀）、
  `gnioq8`（上海音白讀變體）兩音，分別為**質韻**、**屋韻**。由於蘇滬混合腔推薦使用
  白讀 `gniuq8`、文讀 `yuq8`，故特此命名。
- **質**：傳統吳語讀 `tseq7`，但有 `tsyu5` 的後起另讀。為尊重吳語傳統讀音，
  將 `eq` 韻命名為質韻。

## 頁面用法

- 右上角可切換 **漢語（繁體中文）／English／日本語**（也接受 `?lang=wu|en|ja`，
  選擇記在 `localStorage`）。只有介面文字翻譯，**字、音值、韻目一律不譯**。
- **分韻總表**每一格是一個呼位（如「泰合」「灰開」）。格內的數字是該呼位的轄字數，
  點下去列出該呼位全部的字；再點其中一個小韻，就是該小韻的全部轄字。
- **韻圖**預設全部收合，點韻名才展開該韻的聲母／聲調圖，也可一次全部展開。
- **漢字韻圖位置查詢**：輸入最多 8 個漢字（繁體、簡體都行），按韻圖位置分條列出
  該字的每一個讀音。位置字串的形式是「**聲母（或清零／濁零）＋韻目＋呼＋聲調名**」，
  例如 `聲 → 心打開陰平 san1`、`越 → 濁零雪齊陽入 yiq8`。位置字串三語一律不譯。
- **同韻查詢**／**歌詞押韻查詢**：輸入漢字，列出同韻（或近韻相押）的字。
  歌詞押韻查詢另有一張「近韻相押」表，由使用者自己勾選。

以上查詢功能皆可由網址直接開啟：`?pf=<漢字>`、`?pf=<漢字>&syl=<讀音>`、
`?song=1`。字音查詢網站（<https://siqyin.github.io/wugniu_zyinzozin/>）
的「蘇滬混合腔」一欄會在音標後附上韻圖位置標籤，點擊即跳到本頁對應位置。

## 字音資料同步

頁面開啟時會即時讀取
[蘇滬混合腔字音查詢](https://siqyin.github.io/wugniu_zyinzozin/) 的
`data/DB_suhu.json`，在瀏覽器裡重新分韻、重新排圖。
**字音查詢那邊新增字或補上讀音之後，重新整理本頁就會看到最新的字**，不必重新發布。
連不上網路時自動改用頁面內建的離線快照，並顯示提示。

## 檔案

### 頁面與資料

| 檔案 | 內容 |
|---|---|
| `index.html` | 線上頁面本體（資料驅動，開啟時即時抓取線上字音庫） |
| `DB_suhu.json` | 蘇滬混合腔字典本體 |
| `scheme.json` | 分韻方案：聲母、聲調、韻母與其音值、呼位、解析規則 |
| `yuntu_data.json` | 韻圖／分韻總表用的整理資料（韻目、呼位、每格轄字） |
| `snapshot.json` | 離線快照（抓不到線上字音庫時使用） |
| `yuntu_pos.json` | 音節→韻圖位置（給字音查詢網站用的精簡版） |
| `s2t.json` | 簡→繁對照表（僅收「有變化且轉換結果在本字典查得到」的字） |
| `firstpaint.txt` | 首屏會用到的字（由 `measure_firstpaint.py` 實測產生） |
| `font_report.json` | 字型分片的 `unicode-range` 報告（由 `make_font.py` 產生） |

### 三語介面

| 檔案 | 內容 |
|---|---|
| `i18n_data.py` | 漢語・English・日本語三語詞表 |
| `phon_wu.html` | 音系簡介浮窗正文（漢語，取自字音查詢網站，逐字照抄） |
| `phon_en.html` | 音系簡介浮窗正文（English，同上） |
| `phon_ja.html` | 音系簡介浮窗正文（日本語，同上） |

術語與字音查詢網站對齊：蘇滬混合腔的英日叫法是
English `the common language`／日本語「**呉越共通語**」（不带「語」）；
吳語本體的日語叫法是「**呉越語**」（带「語」），如「北部呉越語方言」。

### 圖示與字型

| 檔案 | 內容 |
|---|---|
| `favicon.ico` | 分頁圖示（16/32/48/64） |
| `apple-touch-icon.png` | iOS 主畫面圖示（180×180） |
| `fonts/wk-ui.woff2` | 首屏字（介面文字、三語詞表、聲母表、音系總覽、分韻總表） |
| `fonts/wk-dict.woff2` | 展開韻圖、打開彈窗後才出現的字典用字 |
| `fonts/wk-ext.woff2` | 霞鶩文楷收的全部 CJK 字形 |
| `fonts/OFL.txt` | 字型授權 |

頁面用**霞鶩文楷**（LXGW WenKai，SIL OFL 1.1）顯示，因為字典收錄了大量生僻字。
字型由 `make_font.py` 子集化為 woff2 自託管。韻圖預設收合，收合的內容是
`display:none`，瀏覽器不會為它抓字型，所以首屏只下載 `wk-ui`；
展開韻圖或打開查詢面板時才需要 `wk-dict`。

### 腳本

| 腳本 | 作用 |
|---|---|
| `build_data.py` | 由字典資料產生 `scheme.json`／`snapshot.json`／`yuntu_data.json`／`yuntu_pos.json` |
| `generate_html.py` | 產生 `index.html`（內嵌三語詞表、音系浮窗正文、簡繁表） |
| `measure_firstpaint.py` | 用無頭瀏覽器實測首屏可見字，重寫 `firstpaint.txt` |
| `make_font.py` | 產生 `fonts/` 底下的字型子集（依賴 `firstpaint.txt`，需要 fontTools） |
| `make_s2t.py` | 由字音查詢網站的 S2T.json 精簡出 `s2t.json` |
| `make_favicon.py` | 由字音查詢網站首頁的內嵌 base64 圖示切出 `favicon.ico`／`apple-touch-icon.png`（需要 Pillow） |
| `publish.py` | 發佈到 GitHub Pages |

### 重建流程

改了介面文字（`i18n_data.py`、頁面模板）或韻目之後，按下列順序跑：

```bash
python build_data.py          # → scheme/snapshot/yuntu_data/yuntu_pos
python generate_html.py       # → index.html
python measure_firstpaint.py  # 實測磁碟上 index.html 的首屏可見字
<venv python> make_font.py    # → fonts/*.woff2（輸入未變會自動跳過）
python generate_html.py       # 再跑一次，嵌進新的 font_report.json
```

`make_font.py` 依賴 `firstpaint.txt`，而 `measure_firstpaint.py` 實測的是**磁碟上那份
`index.html`**，所以 `generate_html.py` 必須排在 `measure_firstpaint.py` 之前——
漏掉的話新字不會進 `firstpaint.txt`，會掉到 `wk-dict` 那片，首屏反而要等字典字型。
`make_font.py` 需要 fontTools，須用另外裝好的 venv 執行。

## 發佈

線上網址：**<https://siqyin.github.io/wugniu_yundu/>**

本站以 GitHub Pages 發佈，來源是 **`main` 分支根目錄**（分支模式），所以
**每次 push 到 `main` 就是直接上線**，不需要再跑任何建置步驟。
`.github/workflows/pages.yml` 是備用通道，只登記了手動觸發。

若要從本機重新發布：

```bash
export GITHUB_TOKEN=ghp_xxx      # classic token，勾 repo + workflow
python publish.py --name wugniu_yundu
```

推送預設走 `git@github.com`。`publish.py` 只從環境變數讀取權杖，不寫入任何檔案，
也不會把權杖存進 `.git/config`。用完請到 <https://github.com/settings/tokens> 撤銷該權杖。
